# Лабораторна робота: Робота з об'єктами та масивами в JavaScript

Цей проєкт присвячено вивченню об'єктів та масивів у мові JavaScript[cite: 14] на основі індивідуальної предметної області **«Фільмотека»**[cite: 14].

## 🛠 Технології та інструменти
* HTML5 (інтерфейс взаємодії)
* JavaScript (ES6+: методи об'єктів із `this`, `forEach`, `push`, `filter`, `find`, `sort`, `reduce`, взаємодія через `prompt` / `confirm`)[cite: 14]
* GitHub Pages

---

## 📋 Зміст виконаних завдань
1. **Робота з об'єктами:** Створення об'єкта `movie` з властивостями та методом `movieInfo()` для виведення даних, а також додатковим методом `markAsWatched()`[cite: 14].
2. **Робота з масивами та об'єктами:** Створення масиву `filmoteka`, написання функції виведення даних `displayFilmoteka()` та додавання нового елемента через `push()`[cite: 14].
3. **Методи масивів:** Сортування колекції за роком (`sort`), фільтрація непереглянутих фільмів (`filter`) та пошук елемента за критерієм (`find`), а також розрахунок середнього року виходу (`calculateAverageYear`)[cite: 14].
4. **Взаємодія з користувачем:** Інтерактивне додавання нового фільму через інтерфейс за допомогою діалогових вікон `prompt` та `confirm`[cite: 14].
